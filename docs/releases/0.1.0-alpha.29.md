# Maligator 0.1.0-alpha.29

Alpha.28 replaced the collector, the object layout and the native lowering, and added
isolated workers. That left compiled code paying for every call, property access and
class member through runtime helpers, and many Node APIs that packages expect were
still missing. This alpha works on both.

## Highlights

- Keep compiled values in C locals and let the collector walk native stacks. Compiled
  entries own their activation, short read-only functions and call-only closures run
  without a frame or function object, and the hot isolate state sits in one record.
- Guard class members on shared per-class layout cells, and give class-private fields
  program-wide facts: the kinds and class of what they hold, and the element kinds of
  arrays that only those fields reach. Loops carry such reads around their back edge,
  and classes keep their shape past 64 fields.
- Clone higher-order helpers for the callbacks their callers pass, call known functions
  through `f.call`, inline single-use closures together with their loops, and read an
  owner's captured bindings as SSA values.
- Serve computed-key loads and stores from a shared property stub, cache inherited
  setters and accessor rows, build for-in keys from shapes, decide plain `instanceof`
  without `@@hasInstance`, and run linear RegExp patterns without backtracking.
- Run dense Array, `for...of` and fixed TypedArray loops in unboxed regions, read and
  write int32-keyed elements, TypedArray and DataView elements inline, and extend a
  shared buffer for repeated string appends.
- Add Node's fs streams, watchers, `cp` and `glob`, `child_process` sync and async APIs,
  zlib with Brotli, dgram, DNS records, net and TLS servers with client certificates and
  SNI, KeyObjects, signing and X509 certificates, stream `compose` and `pipeline`
  stages, web transform and compression streams, the WebSocket client, `vm.Script` and
  contexts, `diagnostics_channel` and `async_hooks`. Maligator now reports Node 26.
- Link development builds from relocatable fragments by default, compile dependency
  islands in parallel workers, and keep the shared cache within a budget.

The release also hardens certificate parsing, host names holding NUL and oversized HTTP
chunk extensions, and fixes a list of language details: switch scoping, `with`
bindings, Annex B `RegExp.prototype.compile`, Temporal property bags and the order of
class field initialization.

## Refreshed benchmark snapshot

The five-sample snapshot in `bench/baseline.json` measures clean source `1cf304da`.
JavaScript phase checksums matched Node, and the self-compiled compiler emitted the same
code as the Node-hosted one.

| Workload                       |      Snapshot | Alpha.28 snapshot |
| ------------------------------ | ------------: | ----------------: |
| JavaScript, closed compiled    |      358.2 ms |          462.8 ms |
| JavaScript, open compiled      |      438.3 ms |          572.1 ms |
| JavaScript, closed interpreted |    3,422.1 ms |        3,631.5 ms |
| JavaScript, open interpreted   |    3,587.0 ms |        3,741.9 ms |
| Bare HTTP                      | 184,882 req/s |     172,262 req/s |
| Express routes                 |  51,565 req/s |      34,750 req/s |
| Express JSON                   |  36,570 req/s |      25,096 req/s |
| Express form                   |  29,366 req/s |      19,323 req/s |
| Native compiler execution      |       108.2 s |           167.5 s |

Node ran the JavaScript workload in 351.3 ms on the same laptop, so closed compiled
code is now within 2% of it. The self-compile workload emits 149,936,194 code units
across 129 translation units, against 137,251,797 across 123 for alpha.28, and still
takes about 2.3 times as long as the Node-hosted compiler.

Maligator remains a pre-1.0 alpha. The native packages are unsigned and
unnotarized; APIs and internal contracts may change.
