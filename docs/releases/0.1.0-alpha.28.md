# Maligator 0.1.0-alpha.28

Alpha.27 marked the heap on the mutator thread, stored every object field as a tagged
value, kept Map and Set entries in the general ordered table that properties use, and derived native code
from the VM's bytecode bodies. This alpha replaces those foundations and adds isolated
workers on top.

## Highlights

- Run major marking concurrently on native worker threads and minor collections inline.
  Sweep only newly allocated cells, activate ephemerons by marked key, and pace
  collection across all isolates of a process within its CPU quota.
- Give ordinary objects compact layouts with typed fields, and Map, Set and the weak
  collections their own storage. Strings are compact Latin-1 where possible, and JSON
  and UTF-8 work on string segments without widening them.
- Add `maligator:workers` with isolated workers, shared memory and Atomics, transferable
  ports and persistent task pools. Applications run as supervised images, and production
  builds compile roots concurrently on native workers.
- Lower native code from Core SSA storage through persisted, validated native plans.
  Scalar values now cross calls, phis, suspension points and helper boundaries, root
  masks fit any frame width, and oversized functions are outlined into parts.
- Cache inherited getters, polymorphic prototype methods and own properties of
  dictionary-mode functions. Fold more TDZ checks, inline throwing callees and
  class-scope closures, and compile numeric sort comparators into the merge.
- Support Node packages through UPM, verified HTTPS fetch and more Node globals. Express
  request and response records keep their shapes, and HTTP connections reuse their
  transports.

## Refreshed benchmark snapshot

The five-sample snapshot in `bench/baseline.json` measures clean source
`86494bc3`. JavaScript phase checksums matched Node, and the self-compiled compiler
emitted the same code as the Node-hosted one.

| Workload                       |      Snapshot | Alpha.27 snapshot |
| ------------------------------ | ------------: | ----------------: |
| JavaScript, closed compiled    |      462.8 ms |          993.3 ms |
| JavaScript, open compiled      |      572.1 ms |        1,223.6 ms |
| JavaScript, closed interpreted |    3,631.5 ms |        3,897.0 ms |
| JavaScript, open interpreted   |    3,741.9 ms |        4,055.4 ms |
| Bare HTTP                      | 172,262 req/s |     167,673 req/s |
| Express routes                 |  34,750 req/s |      29,498 req/s |
| Express JSON                   |  25,096 req/s |      20,974 req/s |
| Express form                   |  19,323 req/s |      16,791 req/s |
| Native compiler execution      |       167.5 s |           165.1 s |

Node ran the JavaScript workload in 411.6 ms on the same laptop. The self-compile
workload grew with the compiler: it now emits 137,251,797 code units across 123
translation units, against 94,515,465 across 90 for alpha.27, so its time does not
compare one to one.

Maligator remains a pre-1.0 alpha. The native packages are unsigned and
unnotarized; APIs and internal contracts may change.
