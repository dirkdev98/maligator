# Maligator 0.1.0-alpha.4

This alpha closes the native-build and TypeScript-erasure issues found while
validating real Express, Valibot, AsyncLocalStorage, and Drizzle applications
against alpha.3.

## Highlights

- Fixed external linkage for compiled async and generator functions emitted into
  split C translation units. This removes native linker failures in dependency
  graphs containing resumable functions.
- Verified that combined Express and Valibot applications build successfully
  through the product CLI.
- Verified `AsyncLocalStorage` propagation across an awaited callback through the
  split CLI build path.
- Verified the Drizzle `node:sqlite` driver through native compilation, schema and
  CRUD operations, prepared statements, and nested transactions.
- Extended compact TypeScript erasure to mixed default imports with inline named
  type specifiers, such as
  `import express, { type RequestHandler } from "express"`.
- Added distributed self-host compiler coverage for imported exported
  `<const ValueType>` generic arrows.

## Support

This release candidate is intentionally built and packaged only for macOS arm64:

- `@maligator/cli`
- `@maligator/cli-darwin-arm64`
- `maligator-v0.1.0-alpha.4-aarch64-apple-darwin.tar.gz`

The launcher requires Node.js 20 or newer. Applications built with Maligator require
the Rust toolchain pinned by the repository and a C23-capable C compiler.
Web-platform applications also require a C++ compiler and runtime.

## Release integrity

- npm publication requires a fresh web-authenticated login before any package is
  uploaded.
- Platform packages are published before the launcher package.
- Packed package contents, SHA-256 digests, host execution, and an isolated
  launcher installation are checked before publication.

## Known limitations

- macOS x64, Linux arm64/x64, and Windows binaries are not included in this alpha.
- Alpha binaries are unsigned and are not notarized.
- The minimum supported macOS version is not yet fixed.
- Runtime eval accepts JavaScript; TypeScript erasure for runtime eval remains
  deferred.
- The approval-only `test:full:report` release gate has not been run for this
  candidate.
- This is a pre-1.0 alpha; APIs and internal contracts may change.

Report problems at <https://github.com/dirkdev98/maligator/issues>.
