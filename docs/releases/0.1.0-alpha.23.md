# Maligator 0.1.0-alpha.23

This alpha updates the Core optimizer, improves compiler and runtime performance,
and makes performance comparisons and standards checks easier to reproduce.

## Highlights

- Reworked Core storage, analysis invalidation, and call-graph propagation, with
  incremental analysis and bounded optimization work.
- Improved scalar, typed-array, guarded-call, and allocation optimizations while
  preserving fallback behavior and object identity.
- Reduced repeated Core validation, CFG allocation, and dominator edge traversal.
- Added validated property-entry hints for dictionary objects and private fields,
  and removed temporary rest arrays in proven forwarding cases.
- Fixed optimizer correctness regressions, including open call-target guards and
  joins containing non-callable alternatives.
- Added retained, resumable benchmark comparisons and closure-certified compiler
  capture/profiling workflows with independent Node output verification.
- Made Test262 baseline replacement explicit; ordinary checks preserve the baseline.

## Validation and measured performance

The complete five-sample sweep passed across all four JavaScript modes, bare HTTP,
three Express workloads, and self-compilation. The new baseline is committed as
`afc9c5d4` and records clean compiler checkpoint `c3026037`.

| Workload                       | Previous saved snapshot |  New snapshot |
| ------------------------------ | ----------------------: | ------------: |
| JavaScript, closed compiled    |              2,590.9 ms |    2,459.3 ms |
| JavaScript, open compiled      |              2,585.4 ms |    2,450.5 ms |
| JavaScript, closed interpreted |              4,034.5 ms |    3,905.4 ms |
| JavaScript, open interpreted   |              4,041.3 ms |    3,883.8 ms |
| Bare HTTP                      |           160,234 req/s | 162,031 req/s |
| Express routes                 |            27,056 req/s |  27,219 req/s |
| Express JSON                   |            19,436 req/s |  19,879 req/s |
| Express form                   |            15,959 req/s |  16,348 req/s |
| Native compiler execution      |                 198.0 s |       151.6 s |

These are historical snapshot comparisons, not isolated A/B measurements or
comparisons against alpha.22. JavaScript checksums and all self-compile output
checks passed. Five warm self-compile samples ranged from 151.3 to 151.8 seconds.
The output matched Node at 9 translation units and 60,519,834 code units. Cold,
phase, counter, ownership, and runtime-resource checks also passed.

The dictionary-property optimization has a size tradeoff: the isolated earlier
HTTP comparison measured a 1.27% increase in the Express executable. The complete
new snapshot records 10,558,832 bytes. A brief background app update overlapped the
native compiler build; build-cost timings are not used as optimization evidence.

The 25 focused release, baseline, and website-data tests passed. The eleven-stage
normal repository gate passed, including native behavior, UBSan, selected Test262,
and 1,541 WPT subtests. The macOS arm64 package passed the isolated native compiler
application smoke and packed-launcher installation checks. The rebuilt website
passed local page, method, header, version, and browser checks. A duplicate local
preview point in the self-compile chart was corrected before deployment.
Full Test262 and the full release test tier were not rerun for this release;
existing standards baselines retain their known failures.

## Supported packages

This release contains `@maligator/cli` and `@maligator/cli-darwin-arm64` for Apple
Silicon macOS. Other platform packages are not included. Binaries remain unsigned
and unnotarized. This is a pre-1.0 alpha; APIs and internal contracts may change.
