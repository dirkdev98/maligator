# Maligator 0.1.0-alpha.7

This alpha focuses on first-build latency, low-latency development cycles, and a
more useful interpreted test surface.

## Highlights

- Reworked development lowering to stay linear and added a representative Drizzle
  regression. On the development machine, the cold front-end pass for the reported
  schema now completes in about 0.3 seconds instead of the reported 44 seconds.
- Parallelized generated-C compilation, enabled probed ThinLTO, and cached Rust
  inputs, linked binaries, front-end artifacts, and dependency base images across
  compatible build and test invocations.
- Added concise build progress by default and `--verbose` layer timings and cache
  insights for diagnosing cold builds.
- Added a filesystem-event-driven development loop with cached native images,
  dependency-aware rebuilds, live-binding preservation, transactional restarts,
  and last-good-application retention after a failed rebuild.
- Pruned and reprioritized the smoke and check suites so the tiers are disjoint
  while preserving their semantic coverage.
- Added Node-surface `Headers`, `Response`, and local HTTP `fetch` support to
  interpreted `maligator test` runs.
- Fixed TypeScript erasure for literal-only union parameters, multiline generic
  arrow return types, and typed recursive arrow bindings, including the amended
  issue fixtures.

## Support

This release candidate is intentionally built and packaged only for macOS arm64:

- `@maligator/cli`
- `@maligator/cli-darwin-arm64`
- `maligator-v0.1.0-alpha.7-aarch64-apple-darwin.tar.gz`

The launcher requires Node.js 20 or newer. Applications built with Maligator require
the Rust toolchain pinned by the repository and a C23-capable C compiler.
Web-platform applications also require a C++ compiler and runtime.

## Release integrity

- npm publication requires a fresh `npm login --auth-type web` before any package
  is uploaded.
- Platform packages are published before the launcher package.
- Packed package contents, SHA-256 digests, host execution, and an isolated
  launcher installation are checked before publication.

## Known limitations

- The interpreted-test `fetch` surface currently covers local HTTP request/response
  workflows; HTTPS, redirects, streaming bodies, aborts, and automatic decompression
  remain deferred.
- macOS x64, Linux arm64/x64, and Windows binaries are not included in this alpha.
- Alpha binaries are unsigned and are not notarized.
- The minimum supported macOS version is not yet fixed.
- Runtime eval accepts JavaScript; TypeScript erasure for runtime eval remains
  deferred.
- The approval-only `test:full:report` release gate has not been run for this
  candidate.
- This is a pre-1.0 alpha; APIs and internal contracts may change.

Report problems at <https://github.com/dirkdev98/maligator/issues>.
