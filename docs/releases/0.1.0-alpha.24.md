# Maligator 0.1.0-alpha.24

This alpha improves closed-world native specialization, reuses private literal
graphs, and adds a generated platform API with immutable execution metadata.

## Highlights

- Reuse recursively static arrays and objects when the compiler proves their
  identity and mutation cannot be observed. Resolve known literal prototype
  methods directly under locked primordials, preserving normal method semantics.
- Omit generic native bodies and portable fallback code only when every emitted
  caller selects a retained specialization. Keep function identity and debugging
  metadata, and retain executable fallbacks whenever they remain selectable.
- Extend proven numeric, typed-array, object-field, literal-switch, and sort-callback
  specialization, including guarded calls and bounded helper inlining.
- Add `maligator:process` execution metadata and generate platform declarations,
  runtime data, and API documentation from one catalog. Preserve module-namespace
  identity and include execution metadata in compiler and runtime cache identities.
- Correct script strictness and lexical bindings, relocated module state,
  exceptional indexed-loop exits, template string coercion, and Intl/Temporal
  canonicalization. Test262 now preserves source boundaries and faithful verdicts.
- Add an embedded compiler explorer with erasable TypeScript support, shared site
  templates, and dedicated `maligator:process` and `maligator:test` API pages.

## Performance evidence

An isolated five-pair literal workload retained identical output and reduced median
execution time from 698.8 ms to 188.6 ms (73.0%). A broader five-pair JavaScript
comparison found no classified regression; its runtime change was inconclusive.
These measurements compare the two new compiler optimizations against their
immediate parent, not the full release against alpha.23. Cached build-stage timings
do not establish a cold compilation improvement.

## Validation

The final eleven-stage normal gate passed, including 1,581 unit tests, native
integration, UBSan, selected Test262 checks, and 1,541 WPT subtests with no
unexpected results. Focused regressions verify that the string key `"@@iterator"`
remains distinct from `Symbol.iterator` in both compiler selection and native
execution. Full Test262 and the full test tier were not rerun for this release.

The macOS arm64 artifact passed the isolated native compiler application smoke and
packed-launcher installation checks. The rebuilt native website passed exact page,
version, HTTP-method, and browser checks; JavaScript and erasable TypeScript both
compiled successfully in its WebAssembly explorer. The Linux site binary was
cross-built from the same source and generated assets.

## Supported packages

This release contains `@maligator/cli` and `@maligator/cli-darwin-arm64` for Apple
Silicon macOS. Binaries remain unsigned and unnotarized.
