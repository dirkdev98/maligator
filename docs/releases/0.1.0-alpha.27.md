# Maligator 0.1.0-alpha.27

This alpha improves selected runtime operations and compiler planning while removing
experimental optimization machinery that did not earn a place in the release path.

## Highlights

- Add specialized paths for dense arrays, rest arguments, typed arrays, Map and Set
  iteration, object spreads, JSON key snapshots, and owned object slots.
- Make more Core facts and memory proofs demand driven, distribute optimization
  candidates across callers, and improve bounded rest selection and guarded method
  calls. Preserve iterator cleanup and private array alias behavior at those
  boundaries.
- Retire experimental profile-guided optimization and persistent Core module
  caching after their measured trials. Keep the native build artifact cache and
  improve reuse across equivalent npm executable paths.
- Expand hosted CI and release preparation to build and smoke the macOS and Linux
  arm64 and x64 package matrix. Refresh the curated Test262 baseline and improve
  test runner costs and cold-build allowances.
