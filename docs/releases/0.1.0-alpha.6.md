# Maligator 0.1.0-alpha.6

This alpha hardens the Node-compatible HTTP and cryptography surfaces, adds
authentication-grade primitives, and fills process lifecycle compatibility gaps.

## Highlights

- Added `crypto.argon2`, `crypto.argon2Sync`, `crypto.randomBytes`,
  `crypto.randomInt`, `crypto.randomUUID`, `crypto.timingSafeEqual`, HMAC-SHA-256,
  and PBKDF2-SHA-256 with bounded host work and fail-closed entropy handling.
- Scrubbed secret-bearing digest state, derived keys, authentication tags, and
  random output before backing stores are released; hardened asynchronous Argon2
  startup, saturation, cancellation, and callback settlement.
- Updated the shared HTTP parser to llhttp 9.4.3 and made header-limit overflow a
  hard parse failure so framing headers cannot be hidden by truncation.
- Enforced unambiguous request authorities and strict framing across `Mal.serve`
  and `node:http`, including duplicate `Host`, post-header framing failures, and
  network-error responses.
- Added bounded server transaction phases, configurable live server limits, and
  outbound HTTP inactivity deadlines through both the request option and
  `request.setTimeout()`.
- Added process lifecycle and signal events needed by Node-compatible applications,
  and made nested object subset matching recursive in the test API.

## Support

This release candidate is intentionally built and packaged only for macOS arm64:

- `@maligator/cli`
- `@maligator/cli-darwin-arm64`
- `maligator-v0.1.0-alpha.6-aarch64-apple-darwin.tar.gz`

The launcher requires Node.js 20 or newer. Applications built with Maligator require
the Rust toolchain pinned by the repository and a C23-capable C compiler.
Web-platform applications also require a C++ compiler and runtime.

## Release integrity

- npm publication requires a fresh web-authenticated login before any package is
  uploaded.
- Platform packages are published before the launcher package.
- Packed package contents, SHA-256 digests, host execution, and an isolated
  launcher installation are checked before publication.

## Known limitations

- macOS x64, Linux arm64/x64, and Windows binaries are not included in this alpha.
- Alpha binaries are unsigned and are not notarized.
- The minimum supported macOS version is not yet fixed.
- Runtime eval accepts JavaScript; TypeScript erasure for runtime eval remains
  deferred.
- The approval-only `test:full:report` release gate has not been run for this
  candidate.
- This is a pre-1.0 alpha; APIs and internal contracts may change.

Report problems at <https://github.com/dirkdev98/maligator/issues>.
