# Maligator 0.1.0-alpha.25

This alpha expands closed-world static evaluation across primitive values, improves
incremental native builds, and makes large verification workloads more predictable.

## Highlights

- Discover and propagate static values through Core, then materialize only the
  values demanded by observable consumers. Fold certified Boolean, Number, String,
  Symbol, array, descriptor, locale, and error paths while preserving coercions,
  callbacks, mutation visibility, abrupt completion, and wrapper identity.
- Generate one primordial and native-operation catalog for the compiler and runtime.
  Add pinned Unicode transforms, locale-aware case and collation plans, direct string
  kernels, numeric formatting and rounding, static array queries, and reusable
  primitive results.
- Cache stable generated-C object files across builds. Bound translation-unit size,
  naming depth, worker pools, and cold experiment phases so large self-hosted and
  application builds can reuse unchanged partitions without starving shared hosts.
- Reuse WebAssembly artifacts across checkout paths and Cargo feature builds, forward
  the requested Clang optimization level, adopt WASI SDK 34, and split large compiler
  sources to keep cold WASM builds within a bounded memory and time budget.
- Add bounded quick benchmarks, compiler-scale and translation-unit measurements,
  composable verification runners, shared Test262 inputs, and verified remote
  baseline refreshes. The normal developer gate avoids unused native preparation
  and scales timeouts and workers to the selected workload.
- Fix cyclic array joins, `Date` time clipping before Intl projection, filesystem
  timestamp collisions in cache validation, malformed HTTP request teardown,
  self-host fixture isolation, and Node process-event coverage.
- Align shared website headers and API styling, and keep generated site and Explorer
  dependencies reproducible from the package lock.

The five-sample snapshot committed in `02e325b6` records clean compiler source
`ca8f36d2`. JavaScript phase checksums and every self-compile output comparison
matched. It predates the later generated-C object-cache and partitioning work, so it
does not measure those build improvements.

Self-compilation is 31.0% slower than the alpha.24 saved snapshot (167.2 s), while
the emitted workload grew from 64,582,193 to 77,630,898 code units. These are
historical snapshots across different compiler sources, not a matched measurement
isolating a cause. Five samples produced identical output to Node across all eleven
translation units.

## Validation

The current full Test262 baseline, refreshed after complete queue verification,
records 51,893 passed, 1,678 failed, and 7 host-policy skips against corpus
`3655e746`. The full corpus was not rerun at the final release commit.

The final normal developer gate passed its selected unit, native, sanitizer,
Test262, and WPT lanes. The WebAssembly Explorer matched the Node-hosted compiler,
and the macOS arm64 artifact passed its isolated application and packed-launcher
checks. Full Test262 and the full test tier are not release requirements and were
not rerun for this alpha.

## Supported packages

This release contains `@maligator/cli` and `@maligator/cli-darwin-arm64` for Apple
Silicon macOS. Other platform packages are not included. Binaries remain unsigned
and unnotarized. This is a pre-1.0 alpha; APIs and internal contracts may change.
