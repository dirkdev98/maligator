# Maligator 0.1.0-alpha.2

This alpha improves string and regular-expression throughput while preserving the
existing compiler and runtime contracts.

## Highlights

- Inline storage for short strings and reuse of normalized strings.
- Word-at-a-time UTF-16 scans for string and regular-expression operations.
- Allocation-free ASCII regular-expression plans and word-at-a-time literal scans.
- A 20.2% reduction in the consolidated string benchmark time relative to the
  previous committed baseline.

## Support

The intended npm matrix is macOS and glibc-based Linux on arm64 and x64. This local
release candidate has been built, packed, and smoke-tested only for
`aarch64-apple-darwin`; the other three artifacts must be built and validated before
publishing the complete matrix.

The `@maligator/cli` launcher requires Node.js 20 or newer. Applications built with
Maligator require the Rust toolchain pinned by the repository and a C23-capable C
compiler. Web-platform applications also require a C++ compiler and runtime.

## Known limitations

- Windows is not supported.
- Alpha binaries are unsigned, and macOS artifacts are not notarized.
- Minimum supported macOS and glibc versions are not yet fixed.
- The full approval-only `test:full:report` release gate has not been run for this
  candidate.
- This is a pre-1.0 alpha; APIs and internal contracts may change.

Report problems at <https://github.com/dirkdev98/maligator/issues>.
