# Maligator 0.1.0-alpha.9

This alpha restructures development compilation around reusable dependency islands
and fixes the four application regressions reported against alpha.8.

## Highlights

- Split dependency graphs into reusable cache islands that can be compiled in
  parallel and shared by `run`, `dev`, and `test`. Unchanged dependencies, linkage
  validation, fingerprints, and test fragments now stay reusable across commands.
- Kept cached frontend artifacts and test wires lazy and executable from disk,
  avoiding eager deserialization and large in-memory concatenations on hot paths.
- Added cached asset manifests for development runs, so projects using configured
  assets retain fast edit/restart cycles without rebaking unchanged payloads.
- Reduced development-only compiler work with direct ESTree child traversal,
  register retention, and a minimal correctness-preserving IR pipeline. Verbose DX
  measurements now expose cold compiler phases for representative applications.
- Fixed compact TypeScript erasure for `const` generic arrows, comparison operators
  preceding nested typed factories, and logical negation after `return`.
- Fixed `maligator:test` fetch requests that receive a native `Headers` instance,
  including local Express JSON request/response flows.

## Support

This release candidate is intentionally built and packaged only for macOS arm64:

- `@maligator/cli`
- `@maligator/cli-darwin-arm64`
- `maligator-v0.1.0-alpha.9-aarch64-apple-darwin.tar.gz`

The launcher requires Node.js 20 or newer. Applications built with Maligator require
the Rust toolchain pinned by the repository and a C23-capable C compiler.
Web-platform applications also require a C++ compiler and runtime.

## Release integrity

- The immutable GitHub prerelease contains the exact checked npm tarballs and
  `packages.json` checksum manifest produced on the release host.
- Publishing is performed by the repository's GitHub Actions workflow through npm
  trusted publishing with a short-lived OIDC identity and no stored npm token.
- Platform packages are published before the launcher package; matching registry
  integrity allows an interrupted workflow to resume without replacing artifacts.
- Packed package contents, SHA-256 digests, host execution, and an isolated launcher
  installation are checked before the GitHub release is published.

## Known limitations

- The interpreted-test `fetch` surface currently covers local HTTP
  request/response workflows; HTTPS, redirects, streaming bodies, aborts, and
  automatic decompression remain deferred.
- macOS x64, Linux arm64/x64, and Windows binaries are not included in this alpha.
- Alpha binaries are unsigned and are not notarized.
- The minimum supported macOS version is not yet fixed.
- Runtime eval accepts JavaScript; TypeScript erasure for runtime eval remains
  deferred.
- The approval-only `test:full:report` release gate has not been run for this
  candidate.
- This is a pre-1.0 alpha; APIs and internal contracts may change.

Report problems at <https://github.com/dirkdev98/maligator/issues>.
