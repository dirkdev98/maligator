# Maligator 0.1.0-alpha.36

This alpha adds source-level asset declarations, Fetch API servers and a
promise-based file API. It also ships prebuilt development runners and improves
reuse across warm application builds.

## Application APIs

- Declare files and directories with `embedFile` and `embedDirectory` from
  `maligator:assets`. Builds embed reachable assets into the executable.
  Development commands read them from disk and can run a frontend build or start
  a development server.
- Serve a Fetch API handler with `serve` from `maligator:http`. Use `serveAsset`
  to serve an embedded directory, including a fallback for client-side routes.
- Use `maligator:fs` for file and directory handles, streams, watching, exclusive
  writes, and filesystem path operations.
- Remove `surface` from build configuration and `--surface` from CLI commands.
  The compiler now selects Node.js modules and Web APIs by use.

## Development and builds

- Start a project with `maligator init`. Commands have their own help, and
  compiler errors show source locations.
- Run, watch, and test with a packaged runner when the configuration matches it.
  These commands can start without a native toolchain and skip runtime source
  extraction. Development restarts retain listening sockets on the same address
  and port.
- Production builds can use packaged Rust archives and fetch the pinned Zig
  toolchain on demand. Warm builds reuse generated C, asset declarations and
  cached diagnostics. Test discovery reuses suite manifests and skips file
  metadata reads on unrelated entries.

## Runtime and compatibility

- Follow Node.js package exports and imports resolution. Support arbitrary-size
  BigInts and improve number, date, and duration formatting.
- Use the native Fetch implementation for streamed bodies, redirects and
  compressed responses. Request and Response also accept async iterable bodies.
- Support repeated byte patterns in `Buffer.alloc`, socket idle timeouts,
  CA certificates supplied as Buffer views, and hostname verification when TLS
  wraps an existing socket.
- Improve compiled property access, interpreter dispatch and closure allocation.

The native packages remain unsigned and unnotarized. macOS packages require
macOS 15 or newer. Linux packages require glibc 2.31 and kernel 5.10 or newer.
