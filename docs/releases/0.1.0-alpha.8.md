# Maligator 0.1.0-alpha.8

This alpha restores CommonJS named-import semantics in the low-latency development
path and removes an artificial native-code generation ceiling for large application
graphs.

## Highlights

- Preserved the actual CommonJS `module.exports` value across cached development
  fragments. Forwarding entrypoints such as Express now expose named imports like
  `Router` consistently under `maligator run`, `maligator test`, and native builds.
- Reworked generated-C translation-unit packing to include only declarations each
  unit references. Large metadata arrays are now checked against their real total
  compiler input size instead of being charged for every unrelated declaration.
- Added end-to-end split-image coverage for CommonJS forwarding packages and a
  bounded-unit regression that exercises declaration-heavy native graphs.
- Hardened immutable GitHub prerelease publishing with npm trusted publishing,
  verified release assets, integrity-aware partial-publication retries, and guarded
  manual workflow recovery.

## Support

This release candidate is intentionally built and packaged only for macOS arm64:

- `@maligator/cli`
- `@maligator/cli-darwin-arm64`
- `maligator-v0.1.0-alpha.8-aarch64-apple-darwin.tar.gz`

The launcher requires Node.js 20 or newer. Applications built with Maligator require
the Rust toolchain pinned by the repository and a C23-capable C compiler.
Web-platform applications also require a C++ compiler and runtime.

## Release integrity

- The immutable GitHub prerelease contains the exact checked npm tarballs and
  `packages.json` checksum manifest produced on the release host.
- Publishing is performed by the repository's GitHub Actions workflow through npm
  trusted publishing with a short-lived OIDC identity and no stored npm token.
- Platform packages are published before the launcher package; matching registry
  integrity allows an interrupted workflow to resume without replacing artifacts.
- Packed package contents, SHA-256 digests, host execution, and an isolated launcher
  installation are checked before the GitHub release is published.

## Known limitations

- The interpreted-test `fetch` surface currently covers local HTTP request/response
  workflows; HTTPS, redirects, streaming bodies, aborts, and automatic decompression
  remain deferred.
- macOS x64, Linux arm64/x64, and Windows binaries are not included in this alpha.
- Alpha binaries are unsigned and are not notarized.
- The minimum supported macOS version is not yet fixed.
- Runtime eval accepts JavaScript; TypeScript erasure for runtime eval remains
  deferred.
- The approval-only `test:full:report` release gate has not been run for this
  candidate.
- This is a pre-1.0 alpha; APIs and internal contracts may change.

Report problems at <https://github.com/dirkdev98/maligator/issues>.
