# Maligator 0.1.0-alpha.5

This alpha introduces the first-class test runner and extends the build cache from
frontend artifacts through generated native objects.

## Highlights

- Added `maligator test` with isolated per-file registration, lifecycle hooks,
  matchers, diagnostics, and a typed public test API.
- Added interpreted test execution from relocatable bytecode fragments, including
  debug metadata and a safe whole-image fallback when incremental linkage cannot be
  used.
- Compiled shared incremental test images while preserving file boundaries and
  containing failures to the affected image.
- Added content-addressed caching for native frontend definitions and generated
  objects, with metadata validation that rejects stale or incompatible entries.
- Extended compact TypeScript erasure to object-method parameter and return type
  annotations.
- Decoupled portable wire loading from the host registry so cached and interpreted
  artifacts retain their own module identity.

## Support

This release candidate is intentionally built and packaged only for macOS arm64:

- `@maligator/cli`
- `@maligator/cli-darwin-arm64`
- `maligator-v0.1.0-alpha.5-aarch64-apple-darwin.tar.gz`

The launcher requires Node.js 20 or newer. Applications built with Maligator require
the Rust toolchain pinned by the repository and a C23-capable C compiler.
Web-platform applications also require a C++ compiler and runtime.

## Release integrity

- npm publication requires a fresh web-authenticated login before any package is
  uploaded.
- Platform packages are published before the launcher package.
- Packed package contents, SHA-256 digests, host execution, and an isolated
  launcher installation are checked before publication.

## Known limitations

- macOS x64, Linux arm64/x64, and Windows binaries are not included in this alpha.
- Alpha binaries are unsigned and are not notarized.
- The minimum supported macOS version is not yet fixed.
- Runtime eval accepts JavaScript; TypeScript erasure for runtime eval remains
  deferred.
- The approval-only `test:full:report` release gate has not been run for this
  candidate.
- This is a pre-1.0 alpha; APIs and internal contracts may change.

Report problems at <https://github.com/dirkdev98/maligator/issues>.
