# Maligator 0.1.0-alpha.35

This alpha fixes borrowed FFI handles during incremental garbage collection,
reduces allocation in common runtime paths, and updates native dependencies and
build tools. The macOS packages now require macOS 15 or newer.

## Runtime and compiler

- Borrowed FFI handles recovered during an incremental sweep remain valid for
  their caller. Exhausted Map and Set iterators release their collection targets
  (#102).
- Small arrays, ArrayBuffers and native function slots use storage inside their
  owning cells. Constructor field reservations and unobserved RegExp results avoid
  additional allocations.
- Numeric Array and Math loops, numeric radix sorting, virtual arguments and
  direct helper calls have more specialized compiled paths.
- Repeated class evaluations keep captured state separate. Non-extensible
  functions retain their lazy prototype behavior.
- Synchronous Readable pushes preserve order, and Response initialization follows
  Web IDL conversion order.
- Development rebuilds detect files added to or removed from configured asset
  directories.
- Detached and out-of-bounds DataView metadata returns zero, following the current
  ECMAScript contract. Accessing the view's data still throws where required.

## Dependencies and compatibility

- Update SQLite, ICU4X, the RegExp and URL backends, Rust codecs and cryptography,
  JavaScript integrations, and the compiler toolchain.
- Accept Clang 23's nested anonymous-record type names in FFI bindings.
- Preserve likely-subtag defaults, automatic relative-time literals and empty
  first-day locale fields with the updated ICU backend.
- RegExp matching and string casing use Unicode 18 data. Source-hosted compilation
  still validates RegExp literals with the host engine, so literals naming newly
  added scripts require a host with matching Unicode support. Patterns passed to
  the RegExp constructor do not have this frontend restriction.

The native packages remain unsigned and unnotarized. APIs and internal contracts
may change before 1.0.
