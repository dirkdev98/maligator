# Maligator 0.1.0-alpha.34

Alpha.33 let a borrowed C handle expose a counted array, but a scalar member such as a
`double` still needed a C getter. This alpha adds the field fact for that, from the first
reports against alpha.33.

## C libraries

- `fields: { ascent: { value: true } }` exposes a value member as a read-only property
  on any handle. A library-owned pointer handle otherwise keeps its members hidden, so
  this reads a record the library returns by pointer without a C getter (#96).
- The [C libraries guide](https://maligator.ddv.tools/guides/c-libraries) now opens with
  a tutorial that binds a small library from sources, maps each kind of C behavior to the
  fact that describes it, and splits pointers, resources, callbacks, and globals, unions
  and variadics into their own pages.

Maligator remains a pre-1.0 alpha. The native packages are unsigned and unnotarized;
APIs and internal contracts may change.
